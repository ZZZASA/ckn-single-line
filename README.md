# CKN Single Line

แผนผังสวิตชิ่ง สถานีไฟฟ้าเชียงของ (กฟส.เชียงของ และ กฟฟ.ในสังกัด) — เว็บดูแบบ PDF พร้อมค้นหาอุปกรณ์ ซูม และโหมดกลางคืน

## ไฟล์

- `index.html` — หน้าเว็บ
- `drawing-data.js` — ไฟล์แบบ PDF ที่ฝังไว้ (base64) ให้หน้าเว็บเปิดอัตโนมัติ
- `drawing.pdf` — ไฟล์แบบต้นฉบับ (ปุ่ม "เปิด PDF")
